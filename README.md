# To-Do List

A simple Android To-Do List application built with Kotlin and Android Studio.

## Features

- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean interface

## Built With

- Kotlin
- Android Studio
- Android SDK
- Gradle
